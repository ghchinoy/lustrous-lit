# `<lustrous-skeleton>`

Decorative loading placeholder shimmer (`aria-hidden="true"`). Pair with `aria-busy="true"` on the surrounding region; shimmer animation disables automatically under `prefers-reduced-motion: reduce`.

| Attribute | Values | Default |
| :-- | :-- | :-- |
| `shape` | `rect` · `circle` · `text` | `"rect"` |
| `width` | Number (`px`), `"full"`, or CSS length | `"100%"` (`"40px"` for `circle`) |
| `height` | Number (`px`), `"full"`, or CSS length | `"16px"` (`"40px"` for `circle`) |
| `border-radius` | `none` · `xs` · `s` · `m` · `l` · `xl` · `2xl` · `full` | Shape default |
