# `<lustrous-button>`

Form-associated action button and link button (`href`).

- **Variants:** `accent` (default) · `tonal` · `outline` · `bright` · `on-surface` · `on-surface-variant` · `translucent`
- **Sizes:** `m` (44px, default) · `s` (36px) · `xs` (28px)
- **Shapes:** `rounded` (default) · `pill`
- **Icons & Disclosure:** `icon`, `trailing-icon`, `expanded`
