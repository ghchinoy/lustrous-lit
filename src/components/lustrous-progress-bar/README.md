# `<lustrous-progress-bar>`

Determinate linear progress bar (`0–100`) with `ElementInternals` `role="progressbar"` semantics, semantic `tone` variants, and `forced-colors` `Highlight` fill support.

| Attribute | Values | Default |
| :-- | :-- | :-- |
| `value` | `0`–`100` (clamped) | `0` |
| `label` | Accessible progressbar label | `""` |
| `tone` | `default` · `accent` · `positive` · `warning` · `error` | `"default"` |
| `decorative` | Hides duplicate ARIA semantics when adjacent text states progress | `false` |
