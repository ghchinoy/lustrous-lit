# `<lustrous-segmented-control>`

Compact 2–5 option view switcher with equal-width columns, a sliding active pill indicator, WAI-ARIA `tablist` / `tab` keyboard navigation, and `forced-colors` `Highlight` / `Canvas` pill support.

| Property / Attribute | Values | Default |
| :-- | :-- | :-- |
| `.options` | `LustrousSegmentOption[]` (`{ value, label, disabled?, icon?, badge? }`) | `[]` |
| `value` | Selected option value | `""` |
| `label` | Accessible `tablist` name | `""` |
| `variant` | `default` · `transparent` | `"default"` |
| `size` | `s` (32px) · `m` (40px) | `"s"` |
