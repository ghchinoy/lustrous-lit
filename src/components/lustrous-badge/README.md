# `<lustrous-badge>`

Compact 24px pill badge for status and category labels, supporting semantic tones (`default`, `accent`, `positive`, `warning`, `error`) and dual-theme categorical tones (`cobalt`, `emerald`, `amber`, `rose`, `violet`, `teal`).

| Attribute | Values | Default |
| :-- | :-- | :-- |
| `tone` | `default` · `accent` · `positive` · `warning` · `error` · `cobalt` · `emerald` · `amber` · `rose` · `violet` · `teal` | `"default"` |
| `icon` | Optional decorative leading icon | |
