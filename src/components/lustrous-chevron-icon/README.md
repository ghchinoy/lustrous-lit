# `<lustrous-chevron-icon>` and `renderChevron()`

Animated disclosure chevron that rotates smoothly between collapsed and expanded states (`direction="down"` or `"end"`, RTL-aware).

| Attribute | Values | Default |
| :-- | :-- | :-- |
| `expanded` | boolean | `false` |
| `direction` | `down` · `end` | `"down"` |
| `size` | `xs` · `s` · `m` · `l` · `xl` | `"s"` |
| `tone` | `default` · `primary` · `tertiary` · `positive` · `warning` · `error` | inherits |
| `muted` | boolean | `false` |
| `label` | accessible name | `""` |
